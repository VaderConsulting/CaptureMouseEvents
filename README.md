# CaptureMouseEvents

VB6 demo by Vivek Nigam (VersionCompanyName Phoenix English) that polls `GetAsyncKeyState` on a 50 ms timer and shows whether the left mouse button is up or down, inside or outside the app. Open `CaptureMouseEvents.vbp` in the VB6 IDE.
